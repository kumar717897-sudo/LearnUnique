# LearnUnique — AI Study Companion

## Overview
LearnUnique is an AI-powered study companion designed to help students learn from their own study materials. It aims to make learning more organized, interactive, and accessible.

## Key Features
- **Study Material Upload:** Upload study materials for learning and revision.
- **AI Tutor:** Ask questions and get study assistance based on learning materials.
- **Study Guides:** Organize learning content into useful study notes.
- **Quiz and Evaluation:** Practice questions and review learning progress.
- **Progress Tracking:** Review learning activity and performance.

## How to Use
1. Open the LearnUnique application.
2. Upload your study material.
3. Explore the available study and tutoring features.
4. Practice with quizzes and review your progress.

## Project Goal
The goal of LearnUnique is to support students with a more personalized and interactive study experience.

## Technology
Built using Google AI Studio and the technologies included in the project repository.
